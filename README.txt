  1 step - Download the "Research Development" folder.

  2 step - Open the downloded folder from the VS Code IDE.

  4 step - Activate the environment using below command. Use the command prompt for run this command.

           cd env/Scripts/activate

  5 step - Run the application using this command in the command prompt - python app.py
